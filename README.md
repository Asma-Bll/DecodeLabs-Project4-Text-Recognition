# Text Recognition System

This project was developed as part of the DecodeLabs Artificial Intelligence Internship Program.

## Project Goal

Create a basic text recognition system using a pre-trained AI model.

## Features

- Upload image files
- Extract text from images
- Display recognized text
- Modern web interface
- AI-powered OCR recognition

## Technologies Used

- Python
- Flask
- EasyOCR
- HTML
- CSS

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py

Open:

http://127.0.0.1:5000
